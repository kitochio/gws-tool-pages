# gws-tool-pages

gws（Google Workspace CLI）用の自作 OAuth クライアント（Google Cloud プロジェクト `gws-tool-2026`・アプリ名 `gws-tool`）の、ホームページとプライバシーポリシーを置く GitHub Pages。

- 公開 URL: https://kitochio.github.io/gws-tool-pages/ （プライバシーポリシーは `#privacy`）
- 作った理由: OAuth 同意画面を「テスト中」から「本番」に切り替えるには、ホームページとプライバシーポリシーの URL が要る（テスト中のままだと、ログインが 7 日で切れる）。2026-11-09
- バックアップ: git → GitHub（kitochio/gws-tool-pages）のみ。拠点は Mac
- 記録: Vault `infra-changelog/` の gws のトークン切れの件
